# Answer Format Template

The knowledge agent should return answers in the following structure:

```
Answer: <concise human‑readable answer>
Citation: [<Source Type>] <Document Title> (<YYYY‑MM‑DD>)
```

- **Answer**: Summarize the information in one or two sentences.
- **Citation**: Clearly indicate the source type (SOP, Policy, CustomerRecord, Ticket), the document title, and the date of the source.
